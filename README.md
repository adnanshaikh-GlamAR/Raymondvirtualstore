# Raymond Chairman Collection Virtual Store

Static virtual-store experience for the Raymond Chairman Collection jewellery section.

## Features

- Intro video experience with a centered arrow navigation button.
- Jewellery collection scene using the provided reference image.
- Interactive product hotspot with hover description.
- iJewel3D embedded model viewer for the selected jewellery model.

## Run Locally

```bash
python3 -m http.server 8786
```

Then open:

```text
http://127.0.0.1:8786/
```
